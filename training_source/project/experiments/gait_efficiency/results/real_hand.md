## Differences to the first pass (diagnostics; the method above is unchanged)

- Quarter turns per cycle (variant `run`) agree with the first pass to two decimals for all six policies.
- Rhythm differs by up to 0.02 Hz. A plain FFT of the centred PC1 (no Hann window, no zero padding) gives C5s3 0.29, C5s1 0.35, M400 0.29, R1 0.44, A3 0.39, P0 0.23 Hz, the first-pass values; this script uses a Hann window and zero padding to locate the peak.
- Camera check, trial 5: with the window running to the end of the run (35.5 s, past the 30-s drop) the slope is 0.79 and r = 0.982 (first pass: 0.79, r = 0.984). Here the camera window stops at the drop, because after it the fingers keep cycling without the cube.
